<h2 id="edit-content">编辑简历内容</h2>

打开一份简历后，先在“开始”中确认标题，再进入“内容编辑”模式修改画布里的文字。选择已有内容可以继续编辑；需要补充经历、项目、教育或技能时，使用“插入”中的空白章节或章节模板。

- 使用“布局排序”调整章节先后顺序，完成后切回“内容编辑”。
- 删除文字前先确认选中范围，避免误删同一段中的其他内容。
- 对简历做较大调整前，可以先复制一份简历作为备份。

<h2 id="design-layout">调整设计与布局</h2>

在工作台的“我的图片”中可以上传和管理照片，再从编辑器的“插入 → 插入图片”中选择使用。支持 JPEG、PNG 和 WebP 静态图片。图片格式面板可调整尺寸、裁切焦点、圆角、对齐和替代文字；同一张素材可以用于多份简历，各处裁切互不影响。移出素材库不会移除简历、模板或历史记录里已使用的图片。图片会随简历一起预览、发布和导出，请在发布前检查照片是否合适。

“设计”用于修改主题色、字体和文字外观，“布局”用于调整页面留白、内容宽度与区块排列。外观变化会直接反映在画布和预览中。

左侧“大纲”按章节展示文字、图片和分组。点击节点可以选中并定位画布中的内容，展开箭头用于查看组内内容。章节标题第一次点击选中，选中后再次点击即可改名，也可以使用编辑图标。

在“布局排序”模式中，从大纲左侧手柄拖动即可调整同级顺序，插入线会提示放置位置；也可以使用右侧上下箭头，或聚焦节点后按 Alt + ↑ / ↓。按住 Shift 点击同级节点，可连续多选并整体排序。拖动不会自动改变内容的父级。画布也支持直接点选和 Shift 连选，选中后可通过下方层级路径选择父容器。

在节点的“内容操作”菜单或“布局 → 内容组合”中，可以纵向组合、横向排列、解除一层组合，或将内容移入相邻分组、移出一层。按 Esc 可退出多选，排序和组合都可以一步撤销。

要把多段文字与照片排成左右两列，选中文字和一张图片后点击“图片居右”。文字占左列，图片占右列；可在“双列格式”中调整间距和垂直对齐。长文字跨页时保持左列宽度，图片只在起始页显示。需要改变两列结构时，先解除图文组合，再重新选择内容排版。

优先完成内容，再调整设计和布局。这样更容易判断分页是否合理，也能减少内容变化造成的重复排版。

如果你更习惯直接编写结构化文本，可以切换到“Markdown 编辑”。详细语法与使用范围参见 [使用 Markdown 编辑简历](/docs/markdown-editor)。

<h2 id="save-review">保存、历史与预览</h2>

编辑器会显示当前保存状态。离开页面前，请等待状态恢复为已保存。需要撤回近期改动时，可以使用撤销或历史记录；最终发布或导出前，使用“预览”逐页检查内容、链接、分页和留白。

如果保存状态长时间没有更新，请先保留当前页面，确认网络连接后重试，不要同时在多个窗口编辑同一份简历。

历史记录中的“上次保存前”保留最近一次内容保存覆盖前的完整简历。它会随下一次有效保存滚动替换，不占手动历史记录的名额，也不是长期备份。较大的修改前，仍建议手动创建恢复点或复制简历。

<h2 id="resume-trash">恢复误删的简历</h2>

从“我的简历”删除简历后，可以进入“回收站”，在 30 天保留期内恢复。移入回收站时公开页面会停止访问，恢复后保持未发布，需要你重新发布。超过保留期后无法恢复；选择“彻底删除”也无法撤销。
