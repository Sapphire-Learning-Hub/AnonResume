<h2 id="edit-content">Edit resume content</h2>

After opening a resume, confirm its title under **Start**, then switch to **Content editing** to change text on the canvas. Select existing content to continue editing it. To add experience, projects, education, or skills, use a blank section or section template under **Insert**.

- Use **Layout ordering** to rearrange sections, then return to **Content editing**.
- Check the selection before deleting text so nearby content is not removed by mistake.
- Before a large rewrite, consider duplicating the resume as a backup.

<h2 id="design-layout">Adjust design and layout</h2>

Upload and manage photos in **My images** in the workbench, then choose **Insert → Insert image** in the editor. Static JPEG, PNG and WebP images are supported. The image format panel controls size, crop focus, corners, alignment and alternative text. Reuse an image across resumes with independent crops. Removing it from the library does not remove images already used in resumes, templates or history. Images appear in preview, published resumes and exports, so review them before publishing.

Use **Design** for theme colors, fonts, and text appearance. Use **Layout** for page spacing, content width, and block arrangement. Changes appear directly on the canvas and in preview.

The left **Outline** shows text, images and groups beneath each section. Select a node to locate it on the canvas; use its arrow to expand a group. Click a section title to select it, then click again to rename it, or use its edit icon.

In **Layout ordering**, drag the outline's dedicated handle to reorder siblings. An insertion line shows the destination. Alternatively, use the up/down buttons or focus a node and press Alt + Up/Down. Shift-click sibling nodes to select a consecutive range and reorder it together. Dragging never changes a block's parent. The canvas also supports direct selection and Shift-click ranges; its bottom hierarchy path lets you select parent containers.

Use the node's **Block actions** menu or **Layout → Compose blocks** to group vertically, arrange horizontally, ungroup one level, move into an adjacent group, or move out one level. Press Esc to leave the range selection. Each ordering or composition action is a single undoable operation.

To place a photo beside several text blocks, select the text and exactly one image, then choose **Image on right**. Text occupies the left column and the image the right. Adjust spacing and vertical alignment under **Two-column format**. Text continues on later pages at the same width; the image appears only on the starting page. Ungroup the row first when you need to change its column structure.

Finish the main content before fine-tuning the design. This makes pagination easier to judge and avoids repeating layout work after every content change.

If you prefer writing structured text directly, switch to **Markdown editing**. See [Edit a resume with Markdown](/docs/markdown-editor) for the syntax and supported behavior.

<h2 id="save-review">Save, review history, and preview</h2>

The editor shows the current save status. Before leaving, wait until it returns to saved. Use undo or history when you need to recover a recent change. Before publishing or exporting, open **Preview** and check every page for content, links, page breaks, and spacing.

If the save status does not update, keep the current page open, check your connection, and try again. Avoid editing the same resume in multiple windows at once.

The **Before last save** restore point keeps the complete resume from before the latest content save. It is replaced by the next changed save and does not count toward retained history. It is not a long-term backup: create a restore point or duplicate your resume before major changes.

<h2 id="resume-trash">Recover a deleted resume</h2>

After deleting a resume from your resume list, open **Trash** to restore it within 30 days. Moving it to Trash stops public access. Restored resumes remain unpublished until you publish them again. Expired resumes cannot be restored, and **Delete permanently** cannot be undone.
