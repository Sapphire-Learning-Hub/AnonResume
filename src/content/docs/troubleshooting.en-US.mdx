<h2 id="editing-saving">Editing or saving problems</h2>

If content does not appear immediately, finish the current text edit and check both the canvas and save status. If saving does not finish, keep the page open, check the connection, and try again. Do not edit the same resume in several windows at once.

If content appears in the wrong order, open **Layout ordering** to confirm section positions, then return to **Content editing**. Use undo or history first when recovering from an accidental change.

To undo the latest saved content change, look for **Before last save** in history; the next changed save will replace this point. To recover an entire deleted resume, use Trash in the workspace. If permanent deletion reports unfinished tasks or usage settlement, try again later.

<h2 id="preview-export">Preview, pagination, or PDF problems</h2>

Refresh the page and reopen preview to confirm the problem still occurs. Look for very long paragraphs, many empty lines, oversized images, or content that cannot fit naturally. Shorten the content or adjust page spacing, then preview and export again.

If only the PDF is affected, note the page number and compare the same location in preview.

<h2 id="access-ai">Sign-in, public link, or AI unavailable</h2>

- If sign-in fails, check the email and password and confirm that the email address has been verified.
- If a public link cannot be opened, make sure the resume is still published and copy the link again.
- If there is no AI entry, the current instance does not offer that feature.
- If an AI request fails, submit less content and try later. Contact the administrator if failures continue.

<h2 id="still-need-help">If you still need help</h2>

Open [Get support](/docs/support) and prepare the time, steps, expected result, actual result, and any necessary screenshot. Hide sensitive resume information first.

If an error shows a diagnostic ID, copy it and include it with your report. A local event ID with unconfirmed delivery does not mean the server received the report; also provide the time and page. An error fingerprint helps match errors but is not a request ID.
