<h2 id="import-content">Import existing content</h2>

When creating a resume, you can import supported Markdown content. After the import, review headings, lists, links, and section order. Formatting from another source may need to be reorganized in the editor.

Import helps you begin editing but does not replace a final review. Finish organizing the content before adjusting themes and pagination.

<h2 id="publish-share">Publish and share</h2>

Publishing creates a public page. Open preview before sharing and remove anything you do not want to make public. When you update a resume, the public page reflects its latest published state. Unpublish it when it should no longer be shared.

You can customize the public page without changing the resume content or PDF. See [Public resume appearance](/docs/public-resume-customization) for details.

<h2 id="export-pdf">Export a PDF</h2>

Choose **PDF** to create a file for saving or applications. Before exporting, use preview to check page breaks, fonts, links, and spacing. If the result differs from preview, refresh the page and try again, then see [Troubleshooting](/docs/troubleshooting).

<h2 id="export-account">Export account data</h2>

The account center provides an Excel export for personal reference. It is different from a resume PDF and cannot be imported to restore an account. Before requesting account deletion, export this file and store it safely.
