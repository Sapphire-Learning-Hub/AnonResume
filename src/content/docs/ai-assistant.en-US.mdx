<h2 id="start-request">Start a request</h2>

Open **AI** in the editor, choose an available service, and describe both the content and the outcome you want. A request such as “shorten this project entry while keeping the measured results” is more useful than “make this better.”

Submit only the content needed for the task. Never include passwords, email verification codes, API keys, or unrelated personal information.

<h2 id="review-result">Review before applying</h2>

AI suggestions can omit facts, change the intended tone, or introduce inaccurate details. Before applying a result, check names, dates, numbers, skills, and experience. Make sure the final content is truthful, accurate, and still sounds like you.

If a suggestion is not suitable, revise the request and try again, or use only the useful parts. You remain in control of the final content.

<h2 id="request-problems">When a request does not finish</h2>

- Check your connection and try once more after a short wait.
- Submit less content at a time, or split a complex request into clear steps.
- If the page says no service is available, contact the instance administrator.
- If repeated attempts fail, note the time, steps, and message shown on the page before opening **Get support**.
