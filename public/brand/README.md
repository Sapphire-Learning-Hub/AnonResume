# AnonResume brand assets

The mark, wordmark, and lockup are intentionally separate so the mark can be
used on app icons while the lockup remains suitable for horizontal banners.

- `anonresume-mark.png`: transparent standalone character-and-resume mark
- `anonresume-wordmark.png`: transparent standalone wordmark
- `anonresume-lockup.png`: transparent horizontal mark and wordmark lockup

The PNG files preserve the approved generated artwork exactly. Use the mark
for compact icons, the wordmark when a banner already has a visual anchor, and
the lockup as the default product signature.

This is an original, non-commercial fan-made identity for the open-source
AnonResume project. It is inspired by Chihaya Anon from *BanG Dream! It's
MyGO!!!!!* and is not an official or endorsed BanG Dream! product. Character
and franchise rights belong to their respective owners. See the official
